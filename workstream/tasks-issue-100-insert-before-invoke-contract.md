# Implementation Plan - Issue #100: control plane must insert the queued runs row before invoking

> Source issue: [#100](https://github.com/llipe/dev-tasks-agent-fleet/issues/100) — `docs(agent): control plane must insert the queued runs row before invoking`
> Labels: `documentation`, `priority:medium`, `size:XS`
> Discovery source: [#94](https://github.com/llipe/dev-tasks-agent-fleet/issues/94) reaper verification (§4.0)

## Scope & Decisions

- **Primarily a documentation issue.** The insert-then-invoke contract (D1) is real but currently only fully documented in the operator runbook (`docs/runbooks/issue-94-reaper-verification.md` §4.0). The agent's own `README.md` references it but lacks the ready-to-paste INSERT and the silent-no-op diagnosis. AC1 + AC2 close that gap in the agent docs.
- **Partial coverage already exists.** README §Invocation already: (a) notes a direct CLI invoke does not create the `runs` row (with a #100 link + runbook pointer), and (b) states `run_id` must be caller-generated and the control plane inserts the `queued` row. This plan *completes* that, it does not start from zero.
- **AC3 (SDK change) is OPTIONAL and gated.** The issue hedges it ("Consider…", "If the SDK change is adopted"). It is **not** XS: `agent_reporter.py` is vendored **byte-identical** in two locations (D13) — `agents/dependency-update/app/dependencyUpdate/agent_reporter.py` and `docs/reference/agent_reporter.py` — and a mypy per-module override in `pyproject.toml` depends on the reference copy staying verbatim. Any change must land in **both** files identically and needs new tests. Task 3 is therefore a **decision gate first**, implementation second, and must not silently break the D13 invariant or the "reporting never kills the agent" rule.
- **No migration.** No schema/data-model change. This issue does not touch `001_schema.sql` or seed data.
- **Out of scope:** building the Phase 2 front-end invocation route (explicit issue non-goal). No change to reaper behavior, thresholds, or `cron.schedule`.
- **Repo rules:** no push/merge to `main`; Conventional Commits; `gh issue/pr` bodies via `--body-file`.
