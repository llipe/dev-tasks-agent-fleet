## What

Adds the pnpm workspace root (`pnpm-workspace.yaml` + a delegating root `package.json` exposing the canonical scripts) and the `panel/` Next.js 15 App Router package:

- TypeScript in strict mode
- ESLint, including the SD2 restricted-import guard for `lib/supabase/server`
- Prettier
- Vitest projects for unit / component / integration plus v8 coverage
- Playwright config stub

Also adds `.env.example` with server-only variables and no `NEXT_PUBLIC_SUPABASE_*`, and wires the JS/TS branch into `make validate` and a CI Node job (in progress within this same PR).

## Why

Closes #114

Closes fix proposal F7 — no JS/TS package was reachable from `make validate` or CI. The gate is wired in the same PR that creates the package so the panel is never briefly outside it. Also lays the Phase 2 panel foundation (spec SD1/SD2).

## How

- pnpm workspace with `panel` as a package scoped by `pnpm --filter`.
- Server-only Supabase access enforced by an ESLint restricted-import rule added before the module exists (SD2 guard).
- Dependencies pinned per spec §16.
